KPI Settings

Jira admins only. Build the pieces KPIs need, one at a time or all at once. KPIs can then live in a central KPI space, in any team's space, or both.

1. KPI building blocks

Site-wide pieces only a Jira admin can create. Every space that holds KPIs uses them. Create each one, point the app at one you already have, or skip the optional ones.

    optional
